# 视觉要求

保留 Redthread 原版双层构图、真实主体像素、字体、纸纹和红线模板。同图对照复用同一原图、遮罩、文案和已知配色，并查看实际成图；算法通过不能代替视觉验收。

## 画布与主体

- 画布固定 1200×1600，3:4 比例。上下两个面板各为 1200×800，不因照片比例改变分区。
- `head_box` 覆盖发顶、两侧发型、耳朵、脸和下巴。源图允许时留少量余量；贴边时只保留可用部分。
- `upper_body_box` 包含完整头框，覆盖整个头顶到至少腰部的可见人物。原图只到胸部时保留全部已有上半身，不补造腰部。有腰部的照片不能退成只有头肩。
- 不单独标注、保护或逐指检查指尖。规定上半身范围之外的手部可随整体取景裁剪。`protected_boxes` 默认省略，仅在用户明确要求额外保留区域时使用；显式锚点仍须保留。未填上半身框时，保守保护全部已有 alpha 范围。
- 原图与遮罩采用同一等比缩放和裁切，建立唯一标准 RGBA 主体层。上下使用相同 alpha 和比例；下方只做二维平移，不单独缩小。
- 主体保留原照片的身份、表情、姿势、手型、头发、服饰、道具和有意义的运动模糊。原图已有的身体或道具切口须贴相应画布边缘，不能悬在纸纹或补全背景中。
- 程序只验证标注区域，不识别真实头部或腰部。原图缺失的发顶、身体和道具不能补造。边缘物理冲突仍存在时必须报告，不能宣称合格。

## 上方照片环境

- 优先用原照片铺满上方，保留环境与透视。不得加纸边、照片卡片、黑边、镜像、模糊铺底或拉伸照片。
- 满幅裁切无法保留规定人物范围时，允许等比保留原照片，并仅用 Seedream 5.0 Pro 补上方缺少的环境背景。不改变原版面板比例。
- 固定 helper 锁住有效原照片覆盖范围，并强制覆回原像素。生成图不能提供人物像素，也不能新增人物、身体、发顶、衣物、道具或文字。
- 补全背景须延续原场景的透视、光线、颜色、纹理和景深。检查原图边界接缝及新增异常物体。背景模型不能解决被裁断的人体或道具。
- 单侧完整缺区允许固定 helper 作有限颜色修正。只改变新背景，保留源像素和纹理位置；色相差异明显的边界行须跳过，防止跨材质染色。该检查不识别物体，不能代替接缝和整体效果的视觉验收。
- 将标准主体 RGB 改为白色、暖白或奶油白，alpha 不变。按原图光线加柔和轮廓光晕。剪影以实心为主，只有帮助辨认时才保留很淡的手或道具细节。

## 下方与配色

- 整个下方面板使用 `assets/paper/theme-fiber-paper.jpg`，居中等比裁切，不拉伸，不加局部纸片或阴影掩盖切口。
- 用原图柔和主题色改色，保留纤维、短深色线、纸浆痕迹、扫描柔度和局部明暗。
- 从主题色选择更深的复古红、棕红或砖红。全部文字与红线共用强调色。已有参考配色时按输入保持。
- 下方人物 RGB 只来自原照片，不重建脸、衣物或道具。纸纹和配色由固定 helper 处理，不用生图替代。

## 文字

- 从本图环境、动作、道具和情绪写 3–4 条英文短语，每条宜 2–5 个词，全部位于上方剪影内。优先使用可读的大字号；需要时按单词分成两行，保持词序和短语间距，不拆开单词。
- 两条短日文同字号，优先分别在下方人物左右两侧，避开人物和红线。脚本先尝试左右分置；贴边照片确实放不下时，两句可在有空位的一侧上下错开。此适配只调整文字位置，不改变双层版式、人物比例或保护范围。空间允许时大于英文，不单独缩小其中一条。
- 全部使用 `assets/fonts/dartsfont/DartsFont-Regular.ttf`，渲染前检查字形覆盖。不得用模型生成文字。
- 优先不用标点，并按自然语义换行。较长且未换行的日文可由脚本分成 2–3 行，不改字句；已有换行不变。看图确认断句。
- 使用轻微相反旋转、不完全对称的位置和克制的手写扰动。文案须关联本图，不复制其他照片的示例短句。

## 红线

- 使用 `assets/connectors/templates.json` 原路径，由固定 `scripts/render_connector.py` 绘制。普通任务不单独运行 helper。
- 默认自动选择真实轮廓点；仅用户指定连接点时填写 `anchor` 并保持该点。上下端点须对应同一主体局部点并实际接触。
- 红线连续，有 3–5 个松散、清楚的卷曲。卷曲大小、方向、间距和笔压有变化。
- 保留细、半干的彩铅笔触、轻微边缘纤维和透出底图的细粒，与 DartsFont 协调。
- 完整笔触须避开人物、道具和全部文字，只允许端点必要接触。不用模型、新样条、基础形状、正弦波或随机点替换模板。
- 不使用粗记号笔、实心矢量线、虚线、弹簧、规则 S 曲线或重复圆圈。

## 检查与交付

- 取景、文字和红线搜索由同一固定脚本完成。原有候选共用最多 96 次模板路由；全部失败且未指定连接点时，再尝试更低的真实轮廓点，最多增加 32 次，总计不超过 128 次。它不增加 Agent 调用，不改变人物尺寸，也不通过换版式或删保护扩大可行范围。
- Agent 私下查看全尺寸及约 400 px 宽成图。检查完整头部、规定上半身、道具、切口、分割边缘、背景接缝、文字、锚点及整体比例。
- 程序成功只说明相应检查通过，不等于分割、标注、背景、文案或整体效果已验收。没有实际查看过的图片不能计为视觉通过。
- 一次外部背景生成与同命令续接属于正常两阶段流程。明确输入错误全任务最多修正一次；不得反复生图、换种子、改代码或降低人物保护。细则见[输入说明](input.md#有限修正)。
- 仅发布通过程序和视觉检查的最终 PNG。无法查看、仍有缺陷或存在物理冲突时如实说明，不发布缺陷图。
- 遮罩、主体、红线、图层、背景参考图和检查缩略图均内部使用，不单独展示或链接，不安排“先确认再加滤镜”。
