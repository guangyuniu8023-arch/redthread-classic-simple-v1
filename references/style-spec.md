# 视觉要求

保留 Redthread 的双层结构、真实主体像素、字体、纸纹和红线模板。优先使用原版上方满幅构图。纸纹留边是适配照片的备用版式，与原满幅版式有明确差异，不能称效果逐项完全相同。

## 画布与主体

- 画布固定为 1200×1600，上下两个面板各为 1200×800。输入比例不改变成品比例。
- `head_box` 覆盖完整发顶、头部两侧发型、耳朵、脸和下巴。源图允许时保留少量头部余量；贴边时只保留可用部分，不额外拒绝。
- `upper_body_box` 覆盖完整头顶到至少腰部的可见人物，并包含整个 `head_box`。源图只到胸部时，保留全部已有上半身，不补造腰部。
- 不为放入文字而把有上半身的照片裁成只剩头肩。未提供 `upper_body_box` 时保守保护全部已有 alpha 范围，不凭遮罩猜腰部。
- `protected_boxes` 可保护必须完整保留的手或道具；显式锚点也须保留。
- 原照片和遮罩用相同等比缩放、裁切建立一个标准 RGBA 主体层。上下复用相同像素、alpha 和比例；下方只做二维平移。
- 取景内保留身份、表情、姿势、手型、头发、服饰、道具和有意义的运动模糊。切口须自然，不能悬在纸纹中形成断肢。
- 程序不识别标注是否真的是完整头部和腰部。Agent 必须对照原图检查。原图缺失的身体或发顶不能补造。

只有相对两边同时截到人物、且缩放后主体小于面板时，下层才加同款纸纹卡片。卡片边界承接两处源图切口；纸纹提亮 5.5% 并加轻阴影，使切口有可见边界。主体仍是同一 RGBA，仅平移。单边切口继续贴对应画布边缘。

## 上方与照片比例

- 优先使用原照片填满上方面板，保留环境与透视。
- 满幅容纳不下保护区域或无法完成合格排版时，使用纸纹留边版式：共同缩放、裁切原图和遮罩，将原照片卡片放到同款、同主题色的 `theme-fiber-paper.jpg` 上。
- 卡片保留真实照片内容；留边明确是纸纹，不伪装成原环境。不得黑边、镜像、模糊铺底、生成背景或拉伸照片。
- 将标准主体 RGB 改为白色、暖白或奶油白，alpha 不变。根据原图光线选择柔和轮廓光晕。
- 剪影以实心为主；仅在有助于辨认时保留很淡的手或道具细节。
- 普通长宽比适配由固定脚本内部完成，不把换图作为默认解决办法。

## 下方与配色

- 下方整个背景使用 `assets/paper/theme-fiber-paper.jpg`，居中等比裁切，不拉伸。
- 用原图的柔和主题色改色，同时保留纤维、短深色线、纸浆痕迹、扫描柔度和局部明暗。
- 从主题色选择更深的复古红、棕红或砖红。全部文字与红线使用同一种强调色。
- 将真实主体放到纸纹上，不重建脸、衣物或道具，不为下方排字单独缩小人物。

## 文字

- 从本图的环境、动作、道具和情绪写 3–4 条英文短语，每条宜 2–5 个词，全部位于上方剪影内。
- 两条短日文使用同一字号。优先各放人物一侧；纸纹留边版式允许同侧不同高度排放，仍须避开人物和红线。
- 空间允许时日文大于英文。优先不用标点，自然换成两行；不能单独缩小一条来塞入文字。
- 所有文字使用 `assets/fonts/dartsfont/DartsFont-Regular.ttf`，渲染前检查字形覆盖。
- 较长且未换行的日文可自动分成 2–3 行，不改字句；已有换行不变。视觉检查确认断句自然。
- 使用轻微相反旋转、不完全对称的位置和克制的手写扰动。不用模型生成文字，不复制其他照片的示例短句。

## 红线

- 使用 `assets/connectors/templates.json` 的原路径，由包内 `scripts/render_connector.py` 绘制；普通任务不单独运行该辅助脚本。
- 可见小指优先；否则选其他清楚的轮廓尖端。上下端点映射自同一个主体局部点，须实际接触，不落在旁边空白处。
- 未指定锚点时，程序最多尝试 7 个轮廓候选；显式指定后不换成别处。自动选择不识别小指。
- 线条连续，有 3–5 个松散、清楚的卷曲。卷曲大小、方向、间距和笔压有变化。
- 保留细、半干的彩铅笔触、轻微边缘纤维和透出底图的细粒，风格与 DartsFont 协调。
- 保护取景内人物、道具和全部文字，只允许端点必要接触。检查完整笔触而非仅中心线。
- 不用生成模型、基础形状、正弦波、随机点或新样条替换模板。拒绝粗记号笔、实心矢量线、虚线、弹簧、规则 S 曲线和重复圆圈。

## 检查与交付

- 全部构图搜索在同一固定脚本内完成：先满幅，再最多三个卡片尺度；每次合成最多 288 次模板路由。
- 程序成功只证明相应检查通过，不等于分割质量、头腰标注、文案或整体效果已验收。
- Agent 私下查看全尺寸成图和约 400 px 宽效果，检查完整头部、规定上半身、道具、切口、遮罩残片、文字、锚点和整体比例。
- 缺陷若来自明确的字段、文案或遮罩问题，最多修正一次，再运行固定脚本。不能降低保护、改代码或反复试种子。
- 仅发布通过程序及视觉检查的最终 PNG。无法查看或仍有缺陷时如实说明，不宣称合格。
- 遮罩、主体、红线、图层和检查缩略图保留在内部，不单独展示或链接；不安排“先确认再加滤镜”。
